CC3: Old Age Security (OAS) Payments in Canada

Old Age Security payments are the largest single item in Canada's budget. Many argue they should be reduced, and that the money should go elsewhere.

The above charts call into question whether these payments are needed. OAS has been increasing, yet seniors are significantly wealthier than non-seniors. (Data is sourced from Statistics Canada and open.canada.ca)

CC5 Task 1: Accessing Data via an API

Base URL: https://api.worldbank.org/v2/

Selected Countries: country/kor;jpn;chn/

Indicator for Infant Mortaility Rate: indicator/SP.DYN.IMRT.IN

Other Elements Needed to Call Data: &per_page=1000&mrnev=1000

Returned Data Format: ?format=json

Final URL: https://api.worldbank.org/v2/country/kor;jpn;chn/indicator/SP.DYN.IMRT.IN?format=json&per_page=1000&mrnev=1000
